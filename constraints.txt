# Full transitive dependency lock for Oribots.
#
# requirements.txt pins only the direct dependencies; this file pins the
# complete resolved set (direct + transitive), so a fresh install on a laptop
# and a later install on the HPC resolve to the same versions instead of the
# same direct pins over drifting transitives.
#
# Usage (the constraint applies to whatever pip resolves; it does not itself
# install anything):
#
#     pip install -c constraints.txt -r requirements.txt
#
# Generated with `pip freeze --exclude-editable` from a verified .venv.nosync,
# deliberately excluding the six editable revolve2-* engine packages so no
# absolute `-e /.../engine/...` paths are committed (that would break on the HPC
# and make the checkout non-relocatable). Regenerate the
# same way from a known-good environment if the pinned set needs to change.
#
# Captured on macOS arm64, Python 3.11.15. A wheel occasionally differs between
# macOS arm64 and HPC x86_64; if the HPC install ever conflicts, regenerate this
# file there (or maintain a per-platform constraints file) - the Docker Linux
# gate is where such a divergence would first surface.
